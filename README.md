# Addons Package

Runnable plugin files are stored inside the `Addons/` directory.

## Usage

1. Extract the deployment package.
2. Create an `addons/` folder in the deployment project root.
3. Copy this package's contents into that `addons/` folder.
4. Set `ADDONS=True`.

The `Addons/` folder contains the plugin modules. Root files are metadata or dependency files only.
